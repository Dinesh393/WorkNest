WorkNest

Help and support

Quick guidance for the main WorkNest workflows.

Clients

Post a project, review proposals, and accept a pending proposal to start the project. Use the workspace to follow updates and review the freelancer’s delivery.

Freelancers

Complete your profile, find an open project, and submit a proposal. Use My projects to follow accepted work, post progress updates, and submit a final delivery.

AI features

AI drafts and summaries are optional. Review generated content before using it. If AI is unavailable, continue with the normal project and proposal forms.

Need more help?

WorkNest is maintained as a project application and does not include a support desk. For project-specific help, contact the maintainer through the repository where you received the project.
