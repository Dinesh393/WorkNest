WorkNest

Privacy policy

This page explains the information WorkNest uses to provide project collaboration features.

Information stored by the application

WorkNest may store account details such as your name, email address, and role, along with freelancer profile information, project descriptions, proposals, invitations, progress updates, delivery notes, and notifications.

AI features

When you choose an AI feature, the relevant project summary, project details, profile details, proposal content, or progress notes are sent to the configured AI service to produce a draft or summary. Avoid including passwords, payment credentials, or other sensitive information in these fields.

How information is used

Information is used to display project workspaces, profiles, proposals, invitations, notifications, and other features requested by users. Account and project access is restricted according to the signed-in user and their role.

Local project setup

In a local installation, application data is stored in the configured WorkNest database. The project maintainer controls database hosting, backups, and retention. Do not use real sensitive information in a demo installation.

Changes

This notice may be updated as application features or data handling change. Check this page again after major project updates.
